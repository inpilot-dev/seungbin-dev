## 문제

배포 전 체크리스트를 매번 손으로 밟습니다. 테스트 → 스테이징 → 커밋 메시지 고민 → push.
빼먹으면 사고, 지키면 지겨움.

## 해결

키워드 `배포` 하나에 전 과정을 묶었습니다.

### 순서

- 전체 테스트 실행
- 실패하면 즉시 중단하고 보고
- 통과하면 `git add -A` → diff 분석 → 커밋 메시지 자동 작성 → push

```python
def ship(branch: str) -> None:
    if not run_tests().ok:
        raise SystemExit("테스트 실패 — 배포 중단")
    message = write_conventional_commit(git_diff_cached())
    git_commit(message)
    git_push(branch)
```

## 결과

배포 마찰이 0에 수렴합니다. 실패는 항상 push 전에 잡힙니다.
