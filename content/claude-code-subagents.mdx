## 왜 병렬인가

한 컨텍스트가 들 수 없는 규모의 작업은 쪼개야 합니다. 핵심은 **담당 디렉토리 격리** 와
**머지 게이트** 입니다.

### 불변 규칙

- 담당 디렉토리 밖 수정 금지 — 필요하면 `TODO(track-X)` 주석만
- 공통 타입/토큰만 사용, 새로 만들지 말 것
- 완료 조건: 빌드 통과 + 콘솔 에러 0

## 트랙 나누기

| 트랙 | 담당 |
| --- | --- |
| A | 히어로 |
| B | 리스트/탐색 |
| C | 읽기 경험 |
| D | 인프라 |

```ts
type Track = "hero" | "post-list" | "reader" | "infra";

function ownsPath(track: Track, path: string): boolean {
  return path.startsWith(`components/${track}/`);
}
```

## 머지 게이트

트랙 하나를 머지할 때마다 스모크 테스트를 돌립니다. 문제가 나오면 고치지 말고
**원인과 책임 트랙부터 특정** 합니다.
