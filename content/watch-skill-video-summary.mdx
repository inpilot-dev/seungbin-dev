## 문제

강의·발표 영상을 다 보고 정리하는 데 영상 길이만큼 시간이 든다.
30분 영상 = 30분 시청 + 정리 시간. 이걸 **입력→마법→출력**으로 줄이고 싶었다.

## 파이프라인 (영상마다)

1. **다운로드 + 자막**: yt-dlp로 영상·한/영 자막 추출 (Korean caption 버그 처리)
2. **프레임 추출**: ffmpeg로 자동 스케일 프레임 뽑기
3. **핵심 장면 선별**: 프레임을 직접 보고 강조·다이어그램 장면 고르기
4. **요약 작성**: 자막 + 선별 프레임 기반 한국어 `.md`
5. **스크린샷**: 720p로 핵심 순간 추출

```bash
ffmpeg -nostdin -loglevel error -ss <ts> -i <VID> \
  -frames:v 1 -q:v 2 <OUT> -y
```

## 배치 처리

재생목록·여러 링크를 한 번에 던져도 전부 수집해 순차 처리한다.

- 실패(403·DNS·멤버십·삭제·중복)는 **스킵하고 인덱스에 사유 기록** 후 계속
- 일시적 실패(403/DNS)는 sleep 후 1회 재시도
- 5개 이상이면 3~4개씩 배치 + 배치마다 저장 (작업 증발 방지)

## 출력 규칙

- 파일명 = 영상 제목의 영어 번역(하이픈-케이스)
- 폴더: `<영어제목>/` 안에 `.md` + `screenshots/`
- 이미지 참조는 **상대경로 필수** → Notion import·Obsidian 둘 다 자동 임베드

## 전달

Notion은 Settings → Import → "Markdown & CSV"로 zip import(이미지 자동 임베드).
Obsidian은 폴더째 vault에 복사만.
