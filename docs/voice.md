# 이 목소리가 아닌 것

재발행 초안에 아래가 보이면 내 글이 아니다. 전부 40편 실측 기준이다.

1. **독자를 2인칭으로 부르지 않는다** — "당신" / "여러분" 40편 중 **0건**. 독자를 호명하는 대신 "~한다", "~하면 안 된다"로 규칙만 말한다.

2. **산문에 느낌표를 안 쓴다** — 40편 전체 `!` 11개는 전부 이미지 문법 `![`(5개)와 코드의 `!=` / `!mounted`다. 문장 끝 느낌표 **0건**.

3. **소제목에 물음표를 안 붙인다** — 의문형 소제목("## 왜 병렬인가" `claude-code-subagents.mdx`, "## 언제 DB가 필요해지나" `mdx-file-based-blog.mdx`)이 16개나 되는데 그중 `?`가 붙은 건 **0개**다.

4. **장식용 이모지를 안 쓴다** — 🚀 💡 🔥 🎉 😀 각각 **0건**. 등장하는 기호는 표 셀의 ✅(8회)·❌(6회)와 심각도 라벨 🔴🟡⚪(1편, 4회)뿐이고, 전부 문장이 아니라 라벨 자리다.

5. **과장 형용사를 안 쓴다** — "놀랍게도", "혁신적", "엄청난", "최고의" **0건**. 크기 판단은 형용사가 아니라 숫자로 한다("30MB", "+7.3bp", "연 30% → 4%").

6. **"~하는 법", "튜토리얼" 류 제목을 안 쓴다** — 40편 제목에 0건이고, 본인이 명시적으로 금지어로 선언해뒀다: "\"튜토리얼\", \"~하는 법\", 수치 없는 후기 같은 단어를 **금지 목록**에 넣으면" (`content/prompt-forge-rough-to-good.mdx`).

7. **존댓말(합니다체)은 기본값이 아니다** — 40편 중 3편(`claude-code-subagents.mdx`, `ship-keyword-deploy.mdx`, `youtube-notion-pipeline.mdx`)만 합니다체이고 나머지 37편은 "-다"다. 초안 전체가 합니다체로 나왔다면 기본값을 틀린 것이다.
