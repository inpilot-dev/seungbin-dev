PHP 8.x 전 라인에서 원격 코드 실행 취약점 두 개를 막는 보안 업데이트가 나왔다. 익스플로잇은 이미 어젯밤부터 돌고 있다.

원인은 코드가 아니라 공개 절차의 유출이다. 10월 20일 15:00 UTC쯤 CVE ID 두 개가 포럼과 SNS에 퍼졌다. 같이 돈 릴리스 시각도 틀렸고 CVSS 10.0도 틀렸다. 실제 점수는 9.2다. 기술 세부는 새지 않았다.

PHP 프로젝트는 사전 공지를 19:30 UTC로 당겼다. 릴리스도 10월 22일 14:00 UTC에서 21일 14:00 UTC로 하루 앞당겼다.
---
결정타는 신고자 쪽에서 나왔다. 취약점을 보고한 보안 업체 중 한 곳인 Calif가 20:00 UTC쯤 영상을 실수로 올렸다. 여러 대상에 PoC가 먹히는 장면이 담겼고 제한적이지만 추가 세부도 드러났다. 영상은 지워졌다. 사본은 이미 SNS에 돌았고 PoC 개발이 빨라졌다.

Wiz Research가 8월 24일 보고했고 PHP는 9월 21일 수정에 착수했다. 그렇게 지켜온 엠바고가 공개 직전에 두 번 깨졌다. 한 번은 CVE ID 유출, 한 번은 보고자의 영상이다.

PHP 재단은 보안 체계 강화 방안도 같이 내놨다. 약한 고리는 패치가 아니라 공개 일정을 아는 사람들이었다. Drupal이나 WordPress를 PHP 위에서 돌린다면 지금 쓰는 8.x 라인의 오늘자 패치 릴리스로 먼저 올려야 한다.
